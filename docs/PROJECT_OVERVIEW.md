# Project Overview

## Purpose

A premium portfolio that presents Raj Konde as an AI/ML engineer and aspiring
Generative AI engineer for final-year placements.

## Audience

Recruiters and engineering managers scanning quickly; technical interviewers
who will open a project's case study to judge depth.

## Principles

1. **Honest content.** No invented metrics, achievements, certifications or
   testimonials. Missing data produces empty states, not filler.
2. **Content is data.** Everything personal lives in typed files; components
   render.
3. **Implemented vs planned is explicit**, on the site (project features) and
   in the docs (roadmap).
4. **Works with nothing configured.** Every integration is optional.
5. **Maintainable alone.** Few dependencies, small components, tests that
   catch content mistakes.

## Scope

In scope: static portfolio, project case studies, optional GitHub data,
optional contact form.
Out of scope unless a concrete need appears: database, authentication,
admin panel, CMS.
